Research Focus

GPU memory systems

I design memory-management mechanisms for GPU servers under memory pressure, including prefetching, placement, migration, far-page-fault recovery, and device-side reclamation.

SAFE · ARIADNE · ReclaimX

Heterogeneous CPU–GPU execution

I treat the CPU as an active compute resource in GPU-centric workloads, reducing host-memory traffic and restructuring work so CPU execution can overlap with GPU computation instead of extending the critical path.

ReFlow · ReplayOpt

Workload-aware AI scaling

I use workload-specific sparsity and locality—such as expert routing in Mixture-of-Experts and view-local working sets in 3D Gaussian Splatting—to scale training beyond conventional GPU-memory limits.

Current MoE research · Current 3DGS research

Architecture to full systems

I choose the abstraction level that best matches the bottleneck: GPU architecture simulation with Accel-Sim, full-system simulation with gem5, NVIDIA GPU-driver and UVM development, SIMD-optimized CPU kernels, CUDA/PyTorch systems, or end-to-end server evaluation.
