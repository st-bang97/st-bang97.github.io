Research areas

GPU memory systems

Unified Virtual Memory (UVM) allows GPU workloads to exceed device-memory capacity, but page faults, migration, and thrashing can dominate execution. My work examines how to reduce these costs through adaptive prefetching, memory placement, and device-side reclamation.

I investigate these mechanisms in NVIDIA's GPU driver and through architecture simulation, connecting runtime behavior to the underlying memory system.

LLM & MoE training systems

CPU offload extends training capacity, while introducing optimizer work and data movement across the CPU–GPU boundary. My research focuses on memory-efficient optimizer execution, SIMD, and scheduling that overlaps host work with GPU computation.

I am currently working on scalable and efficient Mixture-of-Experts training on heterogeneous CPU–GPU systems.

Scalable 3D Gaussian Splatting

As a scene's Gaussian population grows, training state places increasing pressure on GPU memory. I study systems techniques for scaling 3DGS training through memory management and CPU–GPU data movement.

Architecture & simulation

My architecture work studies GPU execution and device-side memory-management mechanisms with Accel-Sim. I also work with gem5 and full-system simulation to evaluate memory and high-performance networking systems.
